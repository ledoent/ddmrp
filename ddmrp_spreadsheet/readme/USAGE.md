After installing with demo data, navigate to **DDMRP → Reporting →
Spreadsheets** to open the pre-built dashboard.

The dashboard uses ``=PIVOT()`` dynamic pivot formulas. Each sheet
auto-generates its layout from live DDMRP data — no manual cell
editing is needed.

To customise:

1. Open the spreadsheet and modify pivot definitions (model, domain,
   measures, row/column groupings) via the pivot side-panel.
2. Add KPI alerts on specific cells to get notified when buffer
   metrics cross thresholds.
3. Set up refresh schedules to keep the data current and post
   summaries to the spreadsheet's Chatter.
4. Create subscriptions to receive periodic email digests with
   pivot data snapshots.
